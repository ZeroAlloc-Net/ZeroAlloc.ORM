# ZAO118 — Column placeholder needs a declared dialect

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[Query]` or `[Command]` method uses a `{col:Name}` placeholder and the repository declares no dialect: neither `[Dialect]` on the type nor `[assembly: Dialect]` as the assembly default.

`{col:Name}` writes the column name bare, or quoted when the repository has a `bool` member named `QuoteColumns` and its value is true. The quote style belongs to the dialect: `"Name"` for SQLite and PostgreSQL, `[Name]` for SQL Server, and a backtick on both sides for MySQL. Without a declared dialect there is no style to pick, even when nothing is quoted at run time, so the build refuses.

The diagnostic is reported at the method's name, once for each method that uses a `{col:Name}` placeholder. The `{table}` form needs no dialect and never fires it.

## Fix

Declare the dialect the repository runs on, on the type or on the assembly.

## Example

```csharp
// Fires ZAO118 — no dialect is declared:
public sealed partial class OutboxRepo(IAsyncDbConnection connection, string table, bool quoteColumns)
{
    [Query("SELECT {col:Id} FROM {table}")]
    public partial Task<int> GetAsync(CancellationToken ct);
}
```

Fix: declare the dialect.

```csharp
[Dialect(SqlDialect.PostgreSql)]
public sealed partial class OutboxRepo(IAsyncDbConnection connection, string table, bool quoteColumns)
{
    [Query("SELECT {col:Id} FROM {table}")]
    public partial Task<int> GetAsync(CancellationToken ct);
}
```
