# ZAO002 — Unsupported return type

**Severity:** Error
**Category:** ZeroAlloc.ORM

ZAO002 fires from two different checks in the generator. Both report the same
diagnostic ID, category and severity — the message tells you which one fired.

## Trigger 1 — the return type isn't an awaitable shape at all

Fires when a `[Query]`-annotated method (or a `[Command]`/`[StoredProcedure]`
method that isn't Scalar/Identity) has a return type the generator cannot
emit at all. Allowed shapes are `Task<T>`, `ValueTask<T>`, `IAsyncEnumerable<T>`,
`Task`, and `ValueTask`. Synchronous return types (`T`, `IEnumerable<T>`) and
awaitable types other than the listed ones are rejected. The message reads:

> Method '{0}' has return type '{1}'. Expected Task&lt;T&gt;, ValueTask&lt;T&gt;, IAsyncEnumerable&lt;T&gt;, Task, or ValueTask.

### Fix

Change the return type to one of the supported async shapes. For a single scalar or row, use `Task<T>` or `ValueTask<T>`. For streaming results, use `IAsyncEnumerable<T>` (see ZAO007 for the `[EnumeratorCancellation]` requirement). For commands that return no rows, use `Task` or `ValueTask`.

### Example

```csharp
// Fires ZAO002:
public sealed partial class Repo(IAsyncDbConnection connection)
{
    [Query("SELECT 1")]
    public partial int GetOneAsync(CancellationToken ct);  // sync return type
}

// Fix:
public sealed partial class Repo(IAsyncDbConnection connection)
{
    [Query("SELECT 1")]
    public partial Task<int> GetOneAsync(CancellationToken ct);
}
```

## Trigger 2 — `[Command(Kind = Scalar)]` / `[Command(Kind = Identity)]` can't materialize the value

Fires when a `[Command(Kind = Scalar)]` or `[Command(Kind = Identity)]` method
already returns an awaitable shape (so Trigger 1 above didn't fire) but the
generator still can't build an `ExecuteScalarAsync` reader for it. The message
names the actual problem instead of repeating the return-type shape you
already used:

> Method '{0}' has return type '{1}'. [Command(Kind = {2})] cannot use this return type: {3}.

`{3}` (the reason) is one of:

- **`'{T}' has no scalar reader` / `has no identity reader`** — `T` (the
  `Task<T>`/`ValueTask<T>` type argument, unwrapped of any `Nullable<T>`) isn't
  a type the generator's primitive catalog, value-object, or enum conventions
  can read. `Kind = Scalar` accepts `int`, `long`, `short`, `byte`, `bool`,
  `decimal`, `double`, `float`, `string`, `DateTime`, `DateTimeOffset`,
  `TimeSpan`, `DateOnly`, `TimeOnly`, `Guid`, `byte[]`, an enum, or a value
  object/factory wrapping one of those. `Kind = Identity` narrows that to
  `int`, `long`, or `Guid` (or a value object/factory wrapping one of those).
- **`the result cannot be nullable`** — `Kind = Identity` only, when `T` is
  `Nullable<T>` or an annotated nullable reference. The `RETURNING` /
  `SCOPE_IDENTITY()` contract guarantees a non-null value, so Identity has no
  nullable variant; use `Kind = Scalar` if the value can genuinely be absent.
- **`a scalar command must return Task<T> or ValueTask<T> carrying a value` /
  `an identity command must return ...`**, followed by the same supported-types
  list — the return type is a bare `Task` or `ValueTask` (no type argument) or
  another shape Trigger 1 allows generically (like `IAsyncEnumerable<T>`) but
  that carries no single value for `ExecuteScalarAsync` to read.

### Fix

For the "no reader" reason, change `T` to one of the listed supported types,
or wrap it in a `[ValueObject]` / static factory / enum that the generator's
convention discovery recognizes. For the nullability reason on Identity,
either make the SQL guarantee a value or switch to `Kind = Scalar` and use a
nullable `T`. For the missing-value-shape reason, change the return type to
`Task<T>` or `ValueTask<T>`.

### Example

```csharp
// Fires ZAO002 (Trigger 2) — Uri has no scalar reader; it's not in the
// supported-types list above and doesn't match a value-object/factory/enum
// convention:
public sealed partial class Repo(IAsyncDbConnection connection)
{
    [Command("SELECT SomeUri FROM Widgets WHERE Id = @id", Kind = CommandKind.Scalar)]
    public partial Task<Uri> GetUriAsync(int id, CancellationToken ct);
}

// Fix — read the raw string and construct the Uri at the call site, or wrap it
// in a [ValueObject]/factory type over string:
public sealed partial class Repo(IAsyncDbConnection connection)
{
    [Command("SELECT SomeUri FROM Widgets WHERE Id = @id", Kind = CommandKind.Scalar)]
    public partial Task<string> GetUriStringAsync(int id, CancellationToken ct);
}
```
