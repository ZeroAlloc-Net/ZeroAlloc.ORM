# ZAO108 — LINQ query requires the PostgreSQL dialect

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires on a `[LinqQuery]` method whose repository does not declare PostgreSQL, the only dialect the translator renders. The dialect is the `[Dialect]` on the repository type, else the one on the assembly. A missing dialect fires it too. It is reported at the method.

## Fix

Declare the dialect on the repository or the assembly.

## Example

```csharp
// Fires ZAO108 — no dialect:
public sealed partial class TaskStore(IAsyncDbConnection connection)
{
    [LinqQuery(nameof(TasksQuery))]
    public partial Task<List<TaskSummary>> Tasks(CancellationToken ct);
}
```

Fix by declaring PostgreSQL:

```csharp
[Dialect(SqlDialect.PostgreSql)]
public sealed partial class TaskStore(IAsyncDbConnection connection)
{
    // ...
}
```
