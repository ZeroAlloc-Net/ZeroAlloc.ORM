# ZAO102 — Unsupported LINQ construct

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires on a construct in a `[LinqQuery]` chain that the translator does not turn into SQL, such as an operator from another library, a method of your own, or an operator after `Select`. A chain is translated in full at build time or not at all, so nothing is left to run in memory. The message names the construct, and it is reported at it.

Inside `Where` and `WhereIf` it also fires on a predicate form the translator does not know. The supported forms are:

- `==`, `!=`, `<`, `<=`, `>` and `>=` between columns, companion parameters and constants, and `== null` / `!= null`;
- `&&`, `||` and `!`, and a `bool` column on its own;
- `string.Equals(a, b)`, with or without `StringComparison.Ordinal`;
- `Contains`, `StartsWith` and `EndsWith` on a string column, with or without `StringComparison.Ordinal`, matched literally;
- `Sql.ILike(column, pattern)`;
- `Contains` on an array parameter: `T[]`, `List<T>` or `IReadOnlyList<T>` of `string`, `int`, `long` or `Guid`.

Arithmetic, other methods, other `StringComparison` values, and `<`, `<=`, `>` or `>=` on an enum stored by name are reported. An enum stored by name orders by its names in SQL, not by its values.

## Fix

Use the operators of `ZeroAlloc.ORM.Linq`, with `Select` last. Write the query as a raw `[Query]` when it needs SQL the translator does not produce.

## Example

```csharp
// Fires ZAO102 — Shuffle is not a ZeroAlloc.ORM.Linq operator:
private static IQuery<TaskSummary> TasksQuery() =>
    Sql.Table<TaskEntity>().Shuffle().Select(t => new TaskSummary(t.Id, t.Title));
```
