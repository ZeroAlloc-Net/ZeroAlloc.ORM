# ZAO104 — LINQ entity has no table map

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when the entity in `Sql.Table<T>()` has no `[TableMap]`. The table name comes only from the map. It is reported at the `Sql.Table<T>()` call.

## Fix

Add a map class for the entity. Columns default to the property names; add `[ColumnMap]` only for overrides.

## Example

```csharp
// Fires ZAO104 when no map names TaskEntity:
Sql.Table<TaskEntity>().Select(t => new TaskSummary(t.Id, t.Title));
```

Fix by mapping it:

```csharp
[TableMap(typeof(TaskEntity), "Tasks")]
internal static class TaskMap;
```
