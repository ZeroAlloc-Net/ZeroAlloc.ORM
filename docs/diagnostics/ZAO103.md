# ZAO103 — LINQ query captures a value

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` chain reads a value from outside it: a field, a property of another type, a local or `this`. Values reach the SQL only as parameters, and only the companion's parameters are bound. Compile-time constants are fine; they are inlined as literals. It is reported at the reference.

A member of a companion parameter, such as `minOrder.Value`, is not a capture: it reports [ZAO102](ZAO102.md). `minOrder.HasValue` translates as a null test.

## Fix

Add the value as a parameter of the method and of the companion.

## Example

```csharp
private static readonly string Label = "open";

// Fires ZAO103 — Label is a field:
private static IQuery<TaskSummary> TasksQuery() =>
    Sql.Table<TaskEntity>().Select(t => new TaskSummary(t.Id, Label));
```

Fix by passing it in:

```csharp
[LinqQuery(nameof(TasksQuery))]
public partial Task<List<TaskSummary>> Tasks(string label, CancellationToken ct);

private static IQuery<TaskSummary> TasksQuery(string label) =>
    Sql.Table<TaskEntity>().Select(t => new TaskSummary(t.Id, label));
```
