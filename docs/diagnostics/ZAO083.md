# ZAO083 — [Json] requires a string

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when `[Json]` marks a parameter, record constructor parameter or property whose type is not `string` or `string?`. `[Json]` means "PostgreSQL jsonb; the value is a JSON document held as a string": the generated binding sends the string with `NpgsqlDbType.Jsonb`, so the SQL needs no `::jsonb` cast. Any other type has no such meaning, and that includes `string[]`, which is a PostgreSQL array of text, not one document.

The diagnostic is reported at the attribute, wherever it is written, whether or not a `[Query]` or `[Command]` method uses the member. That includes `[property: Json]` on a positional record parameter, which marks the record's property.

## Fix

Pick one of:

1. Change the type to `string` or `string?` and serialize the document yourself, for example with `System.Text.Json`.
2. Remove `[Json]` if the value is not a JSON document.

## Example

```csharp
public sealed partial class PostRepository(IAsyncDbConnection connection)
{
    // Fires ZAO083: an int is no JSON document.
    [Command("UPDATE posts SET views = @views WHERE id = @id")]
    public partial Task<int> SetViewsAsync(Guid id, [Json] int views, CancellationToken ct);

    // Fix: [Json] on the string that holds the document.
    [Command("UPDATE posts SET doc = @doc WHERE id = @id")]
    public partial Task<int> SetDocAsync(Guid id, [Json] string doc, CancellationToken ct);
}
```
