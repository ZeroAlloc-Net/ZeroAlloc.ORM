# ZAO022 — Return type shape not supported

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a method's return type passes the outer-shape check (`Task<T>`,
`ValueTask<T>`, `IAsyncEnumerable<T>`, `Task` or `ValueTask`, see
[ZAO002](ZAO002.md)) but `T` is not a shape the generator can materialize. The
generator emits no body for such a method, so without ZAO022 the only error
would be the compiler's `CS8795` ("partial method must have an implementation
part"), which does not say why.

The message names the method, the return type and the reason, and the reason
names the shape to use instead:

```
Method '{0}' returns '{1}', which [Query] cannot materialize: {2}
```

| Return type | Reason |
|-------------|--------|
| `Task<TRow>`, a row declared non-nullable | A single row must be nullable; use `Task<TRow?>`, which returns null when the result set is empty. |
| `Task<List<T>>`, `Task<IReadOnlyList<T>>` or `Task<IList<T>>` whose `T` is neither a row nor a scalar | Use a row record whose constructor parameters each bind to a column, or a scalar element such as `int`, `string` or `Guid`. |
| A list of rows with a nullable composite column | Not supported yet; make the composite non-nullable, or read one row at a time as `Task<TRow?>`. |
| `Task<TRow[]>` | An array return reads one PostgreSQL array column; return rows as `List<T>`, `IReadOnlyList<T>` or `IList<T>`, or stream them. |
| `Task<IEnumerable<T>>`, `Task<HashSet<T>>` and other collections | Return `List<T>`, `IReadOnlyList<T>` or `IList<T>`, or stream rows as `IAsyncEnumerable<T>`. |
| A tuple with an element no result set reads | Each element is a scalar, a row or a list of rows. |
| A `[StoredProcedure]` tuple that binds output parameters and is nullable | Remove the `?` from the tuple. |
| A `[StoredProcedure]` output parameter of PostgreSQL array type | Return the array as a result column instead. |
| A bare `Task` or `ValueTask` on `[Query]` | Use `[Command]` to run a statement without a result. |
| Anything else | The message lists the supported shapes. |

ZAO022 is reported only when no more specific diagnostic covers the method:
[ZAO040](ZAO040.md) reports an element type with no construction strategy, and
ZAO043, ZAO044, ZAO051 and [ZAO052](ZAO052.md) report a factory or composite
problem. `[Command]` methods report [ZAO002](ZAO002.md) instead, and an
`IAsyncEnumerable<T>` without `[EnumeratorCancellation]` reports
[ZAO007](ZAO007.md).

Like every error from the generator, ZAO022 stops the generator from emitting
the containing repository, so the other methods of that class report `CS8795`
too until the shape is fixed.

## Supported shapes

- **Scalar:** `Task<T>` or `Task<T?>` for `int`, `long`, `short`, `byte`,
  `bool`, `decimal`, `double`, `float`, `string`, `DateTime`,
  `DateTimeOffset`, `TimeSpan`, `DateOnly`, `TimeOnly`, `Guid` or `byte[]`. The
  nullable form returns null for no row and for NULL. The non-nullable form
  throws `ZeroAllocOrmMaterializationException` for both, except `int`,
  `long`, `bool`, `double` and `decimal`, which return the default value for no
  row.
- **Single row:** `Task<TRow?>`, where `TRow` is a positional record, a class
  with one public constructor, or a composite. No row returns null.
- **List:** `Task<List<T>>`, `Task<IReadOnlyList<T>>` or `Task<IList<T>>`,
  where `T` is a row, or a scalar from the list above, read from the first
  column of every row. A NULL in a non-nullable scalar element throws
  `ZeroAllocOrmMaterializationException`; a nullable element reads null.
- **Streaming rows:** `IAsyncEnumerable<TRow>`, with a `CancellationToken`
  marked `[EnumeratorCancellation]` (see [ZAO007](ZAO007.md)).
- **Multiple result sets:** a tuple such as
  `Task<(TRow Head, List<TLine> Lines)>`, one element per statement (see
  [ZAO032](ZAO032.md) and [ZAO033](ZAO033.md)).
- **PostgreSQL array column:** `Task<T[]>` or `Task<T[]?>` of a primitive
  element, through Npgsql (see [ZAO082](ZAO082.md)).

Every shape above also accepts `ValueTask<T>` in place of `Task<T>`.

## Example

```csharp
public sealed record Row(Guid Id, string Name);

public sealed partial class Repo(IAsyncDbConnection connection)
{
    // ZAO022: a single row must be nullable; use Task<Row?>, which returns
    // null when the result set is empty.
    [Query("SELECT id, name FROM t WHERE k = @k")]
    public partial Task<Row> GetRowAsync(int k, CancellationToken ct);

    // ZAO022: 'IEnumerable<Row>' is not a supported collection.
    [Query("SELECT id, name FROM t")]
    public partial Task<IEnumerable<Row>> GetRowsAsync(CancellationToken ct);
}
```

Fix:

```csharp
public sealed partial class Repo(IAsyncDbConnection connection)
{
    [Query("SELECT id, name FROM t WHERE k = @k")]
    public partial Task<Row?> GetRowAsync(int k, CancellationToken ct);

    [Query("SELECT id, name FROM t")]
    public partial Task<IReadOnlyList<Row>> GetRowsAsync(CancellationToken ct);
}
```

## History

ZAO022 was an `Info` diagnostic until #400. The build output hid it, so an
adopter saw only `CS8795` for the missing body. It is an `Error` now, and its
message names the reason and the alternative.
