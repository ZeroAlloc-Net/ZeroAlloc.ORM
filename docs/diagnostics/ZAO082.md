# ZAO082 — Provider-specific type requires Npgsql

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a PostgreSQL array is bound or read and the project does not reference Npgsql. That covers:

- a `[Query]`, `[Command]` or `[StoredProcedure]` parameter, or a member of a composite parameter, which the message names as the bound parameter, such as `filter_Tags`;
- a row property that a `[Command(Kind = CommandKind.BulkInsert)]` method inserts, such as `Tags` in `record PostRow(int Id, string[] Tags)`;
- a column the result reads: a row or composite member such as `Tags` in `record TaggedRow(Guid Id, string[] Tags)`, or a tuple element of a multi-result return;
- a scalar return such as `Task<string[]>`, which has no column name, so the message names the method.

A PostgreSQL array is one of these shapes:

- `T[]`
- `List<T>`
- `IReadOnlyList<T>`

where `T` is `string`, `int`, `long` or `Guid`. `byte[]` is not an array here: it binds as a binary value on every provider.

Only Npgsql can send these values as a PostgreSQL array. The generator checks for Npgsql by looking for the `Npgsql.NpgsqlParameter` type in your compilation; ZeroAlloc.ORM itself never references Npgsql.

The row collection a `BulkInsert` method takes is not a PostgreSQL array, even when it arrives as an `IReadOnlyList<TRow>`, and does not trigger ZAO082 itself. Nor does a list return such as `Task<List<string>>`: a `List<T>` or `IReadOnlyList<T>` return is never an array, and on a `[Query]` it is a list of rows. Only `T[]` is an array at the return position.

## Fix

Pick one of:

1. Reference the Npgsql package in the project that declares the repository, if the database is PostgreSQL.
2. Bind the values another way on other databases, for example as one delimited `string` that the SQL splits, such as `STRING_SPLIT(@tags, ',')` on SQL Server.

## Example

```csharp
// Fires ZAO082 when the project does not reference Npgsql:
public sealed partial class PostRepository(IAsyncDbConnection connection)
{
    [Query("SELECT COUNT(*) FROM posts WHERE tags && @tags")]
    public partial Task<int> CountTaggedAsync(string[] tags, CancellationToken ct);
}

// Fix: reference Npgsql.
// <PackageReference Include="Npgsql" Version="..." />
```
