# ZAO105 — LINQ member is not a mapped column

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` chain uses an entity member that is not a mapped column. Every public, readable instance property of the entity that holds a value is a column: one with a setter of any accessibility, `init` included, or a get-only auto-property. A field, a property that is not public, or a computed property such as `Label => First + Last` is not. It is reported at the member access.

For an entity from another assembly a private setter is not visible, so a property without a visible setter is a column only when it is an auto-property. A hand-written getter backed by a private setter is left out there, and so is any property the map marks `[ColumnMap(nameof(E.P), Ignore = true)]`.

## Fix

Use a public property of the entity, or write the query as a raw `[Query]`. If the property is stored but was taken for a computed one, name it in the map with `[ColumnMap(nameof(E.P))]`: a `[ColumnMap]` always makes its property a column.

## Example

```csharp
public sealed class Note
{
    public Guid Id { get; private set; }
    internal string Secret { get; private set; } = "";
}

// Fires ZAO105 — Secret is internal:
Sql.Table<Note>().Select(n => new NoteRow(n.Id, n.Secret));
```
