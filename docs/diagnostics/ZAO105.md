# ZAO105 — LINQ member is not a mapped column

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` chain uses an entity member that is not a mapped column. Every public, readable instance property of the entity is a column. A field, or a property that is not public, is not. It is reported at the member access.

## Fix

Use a public property of the entity, or write the query as a raw `[Query]`.

## Example

```csharp
public sealed class Note
{
    public Guid Id { get; private set; }
    internal string Secret { get; private set; } = "";
}

// Fires ZAO105 — Secret is internal:
Sql.Table<Note>().Select(n => new NoteRow(n.Id, n.Secret));
```
