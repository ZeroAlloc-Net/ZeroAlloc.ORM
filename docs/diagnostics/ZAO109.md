# ZAO109 — LINQ companion is called

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires on any call to a method that a `[LinqQuery]` names as its companion. The companion holds the LINQ chain the generator reads at build time; it is never run. Its operators all throw `InvalidOperationException`, and what it would return describes a query, not rows.

Only a call that binds to the companion fires: a method of the same name in another type does not. It is reported at the call.

## Fix

Call the `[LinqQuery]` method that names the companion. The diagnostic message names it. That method runs the SQL generated from the chain and returns the rows.

## Example

```csharp
[Dialect(SqlDialect.PostgreSql)]
public sealed partial class TaskStore(IAsyncDbConnection connection)
{
    [LinqQuery(nameof(OpenTasksQuery))]
    public partial Task<List<TaskSummary>> OpenTasks(int minOrder, CancellationToken ct);

    internal static IQuery<TaskSummary> OpenTasksQuery(int minOrder) =>
        Sql.Table<TaskEntity>()
            .Where(t => t.Order >= minOrder)
            .Select(t => new TaskSummary(t.Id, t.Title));
}

// Fires ZAO109 — OpenTasksQuery never runs:
var query = TaskStore.OpenTasksQuery(3);
```

Fix:

```csharp
List<TaskSummary> tasks = await store.OpenTasks(3, ct);
```

Keep companions `private` so that code outside the repository cannot reach them.
