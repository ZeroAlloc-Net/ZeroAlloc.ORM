# ZAO117 — SQL placeholder not supported here

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `{name}` or `{col:Name}` placeholder appears in SQL that cannot take one:

- the SQL of a `[Command(Kind = CommandKind.BulkInsert)]` method, whose VALUES tuple the generator parses and chunks at build time;
- the name of a `[StoredProcedure]`, or any other stored-procedure SQL.

The diagnostic is reported at the method's name, once for each distinct placeholder.

`[LinqQuery]` and `[LinqCommand]` methods have no case here: their SQL is generated by the translator, so a user cannot write a placeholder in it.

## Fix

Write the table name into the SQL, or move the statement to a `[Command]` or `[Query]` method with the default kind, where placeholders are supported.

## Example

```csharp
// Fires ZAO117 — BulkInsert parses its SQL at build time:
[Command("INSERT INTO {table}(Id, Name) VALUES (@Id, @Name)", Kind = CommandKind.BulkInsert)]
public partial Task<int> InsertAsync(IReadOnlyList<Row> rows, CancellationToken ct);
```

Fix: spell the table.

```csharp
[Command("INSERT INTO Items(Id, Name) VALUES (@Id, @Name)", Kind = CommandKind.BulkInsert)]
public partial Task<int> InsertAsync(IReadOnlyList<Row> rows, CancellationToken ct);
```
