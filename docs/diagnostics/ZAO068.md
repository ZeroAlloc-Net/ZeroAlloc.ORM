# ZAO068 — More than one return value parameter

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when more than one parameter of a `[StoredProcedure]` method is bound
as the procedure's `RETURN` value. A parameter is bound that way by
`[Param(Direction = ParameterDirection.ReturnValue)]`, or by the
`RETURN_VALUE` convention: a parameter whose bound name is exactly
`RETURN_VALUE`, whose tuple field is `int` or `int?`, and whose `[Param]`
writes no `Direction`.

A procedure has one `RETURN` value, and SqlClient fills only one
`ParameterDirection.ReturnValue` parameter. The diagnostic is reported on
each parameter after the first.

## Fix

Keep one of them. Read any other value the procedure produces through an
`OUTPUT` parameter:

```csharp
// Fires ZAO068: status and RETURN_VALUE both read the RETURN value.
[StoredProcedure("dbo.usp_Allocate")]
public partial Task<(int Status, int RETURN_VALUE)> AllocateAsync(
    [Param(Direction = ParameterDirection.ReturnValue)] int status,
    int RETURN_VALUE,
    CancellationToken ct);

// Fix: one RETURN value.
[StoredProcedure("dbo.usp_Allocate")]
public partial Task<(int Status, int Rows)> AllocateAsync(
    [Param(Direction = ParameterDirection.ReturnValue)] int status,
    int rows,
    CancellationToken ct);
```
