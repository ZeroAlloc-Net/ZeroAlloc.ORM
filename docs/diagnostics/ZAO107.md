# ZAO107 — Unsupported LINQ projection

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` chain's `Select` is not one the translator reads. Supported are `Select(t => t.Column)`, one value that one column reads, such as a `string`, an `int`, a `DateTime` or an enum, which the method returns as a list of it; and `Select(t => new Row(...))`, where:

- `Row` is a positional record, constructed through its widest public constructor, the one rows are read with;
- each argument is a mapped column, a companion parameter, or a literal;
- no object initializer is used;
- no constructor parameter of `Row` reads several columns, as a composite or a `[Materialize]` factory type does;
- no argument is a whole object, such as an owned `r.Repository`: project the columns it holds;
- a member of an optional owned object, such as `r.Outcome!.HasFailedValidation` for `AnalysisOutcome? Outcome`, goes to a parameter that takes a null, such as `bool?`, also when it is projected as a group's `g.Key`. It is NULL when the request has no outcome.

After a `GroupBy`, `Select` is required, and each argument is `g.Key`, a member of it, a group aggregate, a companion parameter or a literal. After a `Join`, an argument may also be a member of a joined source, such as `x.Task.Title`. A `GroupBy` without a `Select` fires ZAO107.

Arguments may be named and in any order; each goes to the parameter it binds. A chain without `Select`, and a projection to one value of a type no one column reads, such as a tuple, a typed id or a value object, also fire it. It is reported at the projection or the offending argument.

A scalar terminal such as `Sum` or `Average` returns its value and needs no `Select`.

## Fix

Project into a positional record that holds the columns you need.

## Example

```csharp
// Fires ZAO107 — a tuple is no record and no one column:
private static IQuery<(Guid, string)> PairsQuery() =>
    Sql.Table<TaskEntity>().Select(t => (t.Id, t.Title));
```

Fix by projecting a record:

```csharp
public sealed record TaskPair(Guid Id, string Title);

private static IQuery<TaskPair> PairsQuery() =>
    Sql.Table<TaskEntity>().Select(t => new TaskPair(t.Id, t.Title));
```

One column needs no record: `Select(t => t.Title)` into `Task<List<string>>` reads the titles.

```csharp
// Fires ZAO107 at r.Repository — an owned object is no column:
public sealed record WithRepository(Guid Id, RepositoryReference Repository);

private static IQuery<WithRepository> RequestsQuery() =>
    Sql.Table<CodeAnalysisRequest>().Select(r => new WithRepository(r.Id, r.Repository));
```

Fix by projecting the owned object's members:

```csharp
public sealed record WithRepository(Guid Id, string Url, string? Branch);

private static IQuery<WithRepository> RequestsQuery() =>
    Sql.Table<CodeAnalysisRequest>().Select(r => new WithRepository(r.Id, r.Repository.Url, r.Repository.Branch));
```

```csharp
// Fires ZAO107 — Outcome is optional, so HasFailedValidation is NULL without one:
public sealed record Flag(Guid Id, bool Failed);

private static IQuery<Flag> FlagsQuery() =>
    Sql.Table<CodeAnalysisRequest>().Select(r => new Flag(r.Id, r.Outcome!.HasFailedValidation));
```

Fix by declaring the parameter `bool? Failed`.
