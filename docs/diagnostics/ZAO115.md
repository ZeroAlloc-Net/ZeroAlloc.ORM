# ZAO115 — SQL placeholder finds no string member

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `{name}` placeholder in the SQL of a `[Query]` or `[Command]` method does not bind to exactly one string member of the repository class. The placeholder `{table}` binds to a member of type `string` whose name equals `table`, ignoring case and one leading underscore. The member is one of:

- a primary-constructor parameter;
- a field;
- a property with a getter.

The diagnostic is reported at the method's name, and the message says which case applies:

- no string member matches. The message lists the string members it looked at;
- two or more match, for example `table` and `_table`. The message names them. The usual cause is a primary-constructor parameter and a property or field whose names differ only in case or a leading underscore, such as a parameter `table` and a property `Table`: keep one, and remove or rename the other;
- a member of that name exists, but its type is not `string`;
- a constructor parameter of that name exists but is not a primary-constructor parameter and is never stored, so the generated code cannot reach it.

`{col:Name}` placeholders need no member and never fire this diagnostic.

## Fix

Declare exactly one string member for the placeholder: capture the value in the primary constructor, or store the constructor parameter in a field. Remove or rename the duplicate or the member of the wrong type.

The value is configuration, not input: it is spliced into the SQL text as written. Never bind it to anything a user supplies. Use `@name` and a parameter for values.

## Example

```csharp
// Fires ZAO115 — table is an ordinary constructor parameter that is never stored:
public sealed partial class Repo
{
    public Repo(IAsyncDbConnection connection, string table) { _connection = connection; }
    private readonly IAsyncDbConnection _connection;

    [Query("SELECT COUNT(*) FROM {table}")]
    public partial Task<int> CountAsync(CancellationToken ct);
}
```

Fix: capture it.

```csharp
public sealed partial class Repo(IAsyncDbConnection connection, string table)
{
    [Query("SELECT COUNT(*) FROM {table}")]
    public partial Task<int> CountAsync(CancellationToken ct);
}
```
