# ZAO106 — Invalid entity map

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires on a `[TableMap]` / `[ColumnMap]` pair the LINQ translator cannot rely on. It is reported at the offending attribute, in these cases:

- two `[TableMap]` attributes, on different map classes, name the same entity. The later one, ordered by file path then position, is reported;
- a `[ColumnMap]` names a property the entity does not have, or one that is not a public readable instance property. A computed property is fine: naming it makes it a column;
- the same property has two `[ColumnMap]` attributes. The second is reported;
- two properties map to the same column, whether through `Column` overrides or an override that collides with another property's default name. The later property is reported;
- `EnumAsString = true` is set on a property that is not an enum;
- `DateTimeStorage` is set to `Timestamp` or `TimestampTz` on a property that is not a `DateTime` or `DateTime?`. A `DateTimeOffset` column is always a `timestamptz` and needs no setting;
- `Ignore = true` is combined with `Column`, `EnumAsString` or `DateTimeStorage` on the same `[ColumnMap]`. An ignored property has no column.

## Fix

Keep one `[TableMap]` per entity, name only properties that exist, give each property one `[ColumnMap]`, give each property its own column, set `EnumAsString` only on enum properties, `DateTimeStorage` only on `DateTime` properties, and set nothing else next to `Ignore = true`.

## Example

```csharp
// Fires ZAO106 — Title is a string, not an enum:
[TableMap(typeof(TaskEntity), "Tasks")]
[ColumnMap(nameof(TaskEntity.Title), EnumAsString = true)]
internal static class TaskMap;
```

Fix by mapping the enum property:

```csharp
[TableMap(typeof(TaskEntity), "Tasks")]
[ColumnMap(nameof(TaskEntity.Kind), EnumAsString = true)]
internal static class TaskMap;
```
