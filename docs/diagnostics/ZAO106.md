# ZAO106 — Invalid entity map

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires on a `[TableMap]` with its `[OwnedMap]` and `[ColumnMap]` attributes that the LINQ translator cannot rely on. It is reported at the offending attribute, in these cases:

- two `[TableMap]` attributes, on different map classes, name the same entity. The later one, ordered by file path then position, is reported;
- a `[ColumnMap]` names a property the entity does not have, or one that is not a public readable instance property. A computed property is fine: naming it makes it a column;
- the same property has two `[ColumnMap]` attributes. The second is reported;
- two properties map to the same column, whether through `Column` overrides or an override that collides with another property's default name. The later property is reported;
- `EnumAsString = true` is set on a property that is not an enum;
- `DateTimeStorage` is set to `Timestamp` or `TimestampTz` on a property that is not a `DateTime` or `DateTime?`. A `DateTimeOffset` column is always a `timestamptz` and needs no setting;
- `DateTimeStorage` is set to a value the enum does not declare, such as `(DateTimeStorage)7`, on any property;
- `Ignore = true` is combined with `Column`, `EnumAsString` or `DateTimeStorage` on the same `[ColumnMap]`. An ignored property has no column;
- an `[OwnedMap]` names a property the entity does not have, or one that is not a public readable instance property;
- an `[OwnedMap]` names a property whose type has no properties to map: a primitive such as `string`, an enum, a value object with a `Value`, a `From` factory or a single-argument record, a nullable value type, or a collection;
- the same property has two `[OwnedMap]` attributes. The second is reported;
- a `[ColumnMap]` with a dotted path, such as `"Repository.Url"`, whose first segment is not declared with `[OwnedMap]`;
- a dotted path whose second segment is not a public readable instance property of the owned type, or a path deeper than `Owner.Property`;
- every member of an owned property is ignored or computed, so it has no column to read or to test for null;
- a `[ColumnMap]` names an owned property itself, such as `"Repository"`. Its members are its columns; map each by its dotted path.

## Fix

Keep one `[TableMap]` per entity, name only properties that exist, give each property one `[ColumnMap]`, give each property its own column, set `EnumAsString` only on enum properties, `DateTimeStorage` only on `DateTime` properties, and set nothing else next to `Ignore = true`. Declare each owned property once with `[OwnedMap]`, only on a class or struct whose properties are columns, and map its members by `Owner.Property`.

## Example

```csharp
// Fires ZAO106 — Title is a string, not an enum:
[TableMap(typeof(TaskEntity), "Tasks")]
[ColumnMap(nameof(TaskEntity.Title), EnumAsString = true)]
internal static class TaskMap;
```

Fix by mapping the enum property:

```csharp
[TableMap(typeof(TaskEntity), "Tasks")]
[ColumnMap(nameof(TaskEntity.Kind), EnumAsString = true)]
internal static class TaskMap;
```

A dotted path needs its owner declared owned:

```csharp
// Fires ZAO106 — Repository is not declared with [OwnedMap]:
[TableMap(typeof(CodeAnalysisRequest), "AnalysisRequests")]
[ColumnMap("Repository.Url", Column = "RepositoryUrl")]
internal static class CodeAnalysisRequestMap;
```

```csharp
[TableMap(typeof(CodeAnalysisRequest), "AnalysisRequests")]
[OwnedMap(nameof(CodeAnalysisRequest.Repository))]
[ColumnMap("Repository.Url", Column = "RepositoryUrl")]
internal static class CodeAnalysisRequestMap;
```
