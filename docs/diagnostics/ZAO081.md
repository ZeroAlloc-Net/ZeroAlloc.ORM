# ZAO081 — Containing type must be partial (nested repository)

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a repository is declared *inside* one or more other types (a nested class, struct, or record) and one of those OUTER containing types is not declared `partial`. The generator emits the generated repository class wrapped in a matching partial declaration for every containing type, outermost first, so all of them must be `partial` for the two halves to join.

This is the nested-type counterpart of [ZAO004](ZAO004.md), which covers the repository type itself. ZAO081 covers every type that *contains* the repository type.

## Fix

Add the `partial` modifier to every containing class, struct, or record declaration between the repository and its outermost container.

## Example

```csharp
// Fires ZAO081, naming 'TestApp.Data' — missing 'partial' on the outer type:
public class Data
{
    public partial class OrderRepository(IAsyncDbConnection connection)
    {
        [Query("SELECT 1")]
        public partial Task<int> GetOneAsync(CancellationToken ct);
    }
}

// Fix: every containing type is partial.
public partial class Data
{
    public partial class OrderRepository(IAsyncDbConnection connection)
    {
        [Query("SELECT 1")]
        public partial Task<int> GetOneAsync(CancellationToken ct);
    }
}
```
