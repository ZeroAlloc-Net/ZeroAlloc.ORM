# ZAO112 — LINQ method return type does not fit the query

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` method's return type does not fit its companion's `IQuery<TRow>`. The supported return types are:

- `Task<List<TRow>>`, `Task<IReadOnlyList<TRow>>` or `Task<IList<TRow>>`, for every row;
- `Task<TRow?>`, for the first row or null. The SQL gets `LIMIT 1`;
- the same with `ValueTask` instead of `Task`;
- `IAsyncEnumerable<TRow>`, to stream the rows;
- after `Count()`, `Task<int>`; after `LongCount()`, `Task<long>`; after `Any()`, `Task<bool>`. Each also as `ValueTask`;
- after `Sum`, `Min`, `Max` or `Average`, `Task<T>` with the type the operator returns, such as `double` for `Average` of an `int` or `long`: `int`, `long`, `double` or `decimal`, a nullable one of those, `DateTime?`, `DateTimeOffset?` or `string?`. `Task<double>` and `Task<decimal>` are supported scalar results for `[Query]` too. Also as `ValueTask`.

A terminal's result of any other type fires it: an enum, a `Guid`, a non-nullable `DateTime` or a non-nullable `string`, for example `Max(t => t.Status)` into `Task<WorkStatus>`.

It is reported at the method's return type.

## Fix

Return one of the supported types, with the companion's row type, or the type its terminal produces.

## Example

```csharp
// Fires ZAO112 — a single row must be nullable:
[LinqQuery(nameof(FirstQuery))]
public partial Task<TaskSummary> First(CancellationToken ct);
```

Fix:

```csharp
[LinqQuery(nameof(FirstQuery))]
public partial Task<TaskSummary?> First(CancellationToken ct);
```
