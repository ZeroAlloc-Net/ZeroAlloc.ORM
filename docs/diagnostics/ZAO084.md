# ZAO084 — PostgreSQL-only type on another dialect

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a PostgreSQL array or a string marked `[Json]` is bound or read on a repository whose declared dialect is not PostgreSQL. The dialect comes from `[Dialect]` on the repository type, else from `[assembly: Dialect(...)]`. A repository with no declared dialect is not checked.

It covers every place [ZAO082](ZAO082.md) checks: array and `[Json]` parameters, composite parameter members, array columns of rows, composites, multi-result tuples and scalar returns, and the row properties of a `BulkInsert` method. It is reported at the same location as the matching ZAO082, and does not depend on whether the project references Npgsql.

Only PostgreSQL has arrays and `jsonb` parameters: SQL Server, SQLite and MySQL providers cannot send these values, so the generated code would fail at run time.

## Fix

Pick one of:

1. Declare `[Dialect(SqlDialect.PostgreSql)]` on the repository if the database is PostgreSQL.
2. Bind the values another way on other databases, for example one delimited `string` that the SQL splits. For `[Json]`, remove the marker and bind the plain string.

## Example

```csharp
// Fires ZAO084: SQLite cannot bind a PostgreSQL array.
[Dialect(SqlDialect.Sqlite)]
public sealed partial class PostRepository(IAsyncDbConnection connection)
{
    [Query("SELECT COUNT(*) FROM posts WHERE tags && @tags")]
    public partial Task<int> CountTaggedAsync(string[] tags, CancellationToken ct);
}
```
