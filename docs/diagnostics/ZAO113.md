# ZAO113 — LINQ row lock without a transaction

**Severity:** Warning
**Category:** ZeroAlloc.ORM

## Trigger

Fires when a `[LinqQuery]` chain locks rows with `ForUpdate()`, `ForUpdateSkipLocked()` or `ForUpdateNoWait()`, but the method takes no `IAsyncDbTransaction` parameter. A lock in any element of a tuple companion counts.

PostgreSQL holds a row lock until the transaction that took it ends. A method without a transaction parameter runs its statement in a transaction of its own, unless the connection already has one open, so the lock is released as soon as the statement ends. It guards nothing the caller does afterwards: another writer can change the row between the read and the caller's own update, and two workers claiming from a queue with `SKIP LOCKED` can get the same row on their next statement.

The elements of a tuple companion run as one Npgsql batch, in one implicit transaction, so a lock taken by one element lasts until the batch ends, and no longer. The warning still applies: nothing after the method returns is guarded.

The query is still generated as written. It is reported at the method's name.

## Fix

Take an `IAsyncDbTransaction` parameter, and pass the transaction the caller begins, reads, writes and commits in. The lock then lasts until the caller commits or rolls back.

## Example

```csharp
// Fires ZAO113 — the lock ends with the SELECT:
[LinqQuery(nameof(ClaimQuery))]
public partial Task<List<TaskLine>> ClaimAsync(int count, CancellationToken ct);
```

Fix:

```csharp
[LinqQuery(nameof(ClaimQuery))]
public partial Task<List<TaskLine>> ClaimAsync(int count, IAsyncDbTransaction tx, CancellationToken ct);

private static IQuery<TaskLine> ClaimQuery(int count) =>
    Sql.Table<TaskEntity>()
        .Where(t => t.Status == WorkStatus.Open)
        .OrderBy(t => t.Order)
        .Take(count)
        .ForUpdateSkipLocked()
        .Select(t => new TaskLine(t.Id, t.Title));
```

```csharp
var tx = await connection.BeginTransactionAsync(ct);
await using (tx)
{
    var claimed = await repo.ClaimAsync(10, tx, ct);
    // ... work on the claimed rows; no other worker can claim them ...
    await tx.CommitAsync(ct);
}
```
