# ZAO101 — LINQ companion parameters do not match the method

**Severity:** Error
**Category:** ZeroAlloc.ORM

## Trigger

Fires when the companion's parameters are not the `[LinqQuery]` method's value parameters. The value parameters are the method's parameters without the `CancellationToken` and the `IAsyncDbTransaction`. They must match by name, type and order, because each companion parameter becomes the SQL parameter its method parameter binds. It is reported at the companion's parameter list.

## Fix

Give the companion the method's parameters in the same order, leaving out the `CancellationToken` and the transaction.

## Example

```csharp
// Fires ZAO101 — the order differs:
[LinqQuery(nameof(TasksQuery))]
public partial Task<List<TaskSummary>> Tasks(Guid projectId, int status, CancellationToken ct);

private static IQuery<TaskSummary> TasksQuery(int status, Guid projectId) => ...;
```

Fix by matching the method:

```csharp
private static IQuery<TaskSummary> TasksQuery(Guid projectId, int status) => ...;
```
